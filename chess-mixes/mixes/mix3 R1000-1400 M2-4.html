Последние выбранные задачи (по порядку вкладок)

    После открытия вкладок страница проверит выбранные задачи через API Lichess. Проверка не блокирует вкладки и не гарантирует, что Lichess не изменит задачу позднее.

    ℹ️ Особенности работы с солянкой
    • Одна вкладка — одна задача. Решай только ту задачу, которая открылась. Не нажимай на Lichess кнопку «Следующая задача» — переходи к следующей вкладке.
    • Если Chrome блокирует вкладки. Вернись на вкладку с солянкой. Справа в адресной строке нажми значок блокировки всплывающих окон, разреши их открытие для этой страницы и снова нажми кнопку запуска задач.
    Общие настройки тренировки

    Рейтинг и ходы ограничены сгенерированными задачами. По умолчанию сохранены исходные веса тем.
